# 🌱 Eco Impact Calculator

A simple web-based calculator that estimates a user's daily environmental impact based on transportation, electricity usage, food consumption, and trees planted.

## 📌 About the Project

The Eco Impact Calculator helps users understand how their everyday activities can affect the environment.

Users enter basic information about their daily lifestyle, and the calculator provides an estimated CO₂ impact along with an environmental impact level and eco-friendly suggestions.

## ✨ Features

- 🚗 Calculates impact from car travel
- 🚌 Calculates impact from public transport
- 💡 Calculates electricity-related CO₂
- 🍽️ Estimates food-related CO₂
- 🌳 Considers trees planted as a positive environmental contribution
- 🌍 Displays total estimated daily CO₂ impact
- 📊 Shows individual impact categories
- 💡 Provides personalized eco-friendly suggestions
- 📱 Responsive design for different screen sizes

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html`.
4. Right-click on the file and select **Open with Live Server**.

You can also open `index.html` directly in a web browser.

## 📊 How It Works

The calculator uses approximate emission factors for different daily activities.

The estimated impact is calculated using:

- Car travel
- Public transportation
- Electricity consumption
- Meat meals
- Trees planted

The final result is displayed in kilograms of estimated CO₂.

## 🌱 Impact Levels

### Low Impact
The estimated daily impact is relatively low.

### Moderate Impact
There are some areas where more sustainable choices can reduce the impact.

### High Impact
The user can make significant improvements by adopting greener transportation, energy, and food choices.

## 🎯 Purpose

The purpose of this project is to create awareness about everyday environmental choices and encourage users to adopt more sustainable habits.
